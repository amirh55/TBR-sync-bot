# 🔄 TBR Sync Bot

انتقال لحظه‌ای پست‌های یک کانال **بله** به یک کانال **تلگرام** — متن، عکس، ویدیو، آلبوم، فایل، صوت، مخاطب و موقعیت مکانی، به همراه ویرایش و حذف.

> ⚠️ این ربات فقط برای استفادهٔ شخصی یا تیمی است. پیش از انتشار، قوانین هر دو پلتفرم را رعایت کنید.

---

## این ربات چه کار می‌کند

| | |
|---|---|
| **جهت انتقال** | یک‌طرفه: بله ← تلگرام |
| **روش اتصال به بله** | Bot API خام (`tapi.bale.ai`) با long-polling |
| **روش اتصال به تلگرام** | `python-telegram-bot` — فایل‌ها دوباره آپلود می‌شوند، forward نمی‌شوند |
| **پایتون** | ۳.۱۰ یا بالاتر |

**پشتیبانی می‌شود:** متن با بولد، عکس، ویدیو، گیف، فایل، صوت، ویس، استیکر، آلبوم چندرسانه‌ای، مخاطب، موقعیت مکانی، ریپلای، ویرایش پست، حذف پست.

**پشتیبانی نمی‌شود:** انتقال از تلگرام به بله (یک‌طرفه است)، و روبیکا.

---

## پیش‌نیازها

- یک سرور لینوکسی با systemd (اوبونتو / دبیان)
- **توکن ربات بله** — از `@BotFather` در بله بگیرید
- **توکن ربات تلگرام** — از [@BotFather](https://t.me/BotFather) در تلگرام بگیرید
- ربات بله باید **ادمین کانال مبدأ** باشد
- ربات تلگرام باید **ادمین کانال مقصد** باشد

---

## نصب — یک دستور

```bash
git clone https://github.com/amirh55/TBR-sync-bot.git && cd TBR-sync-bot && bash install.sh
```

اسکریپت نصب به‌صورت خودکار:

1. پایتون ۳.۱۰+ را پیدا می‌کند و در صورت نیاز `python3-venv` را نصب می‌کند
2. محیط مجازی می‌سازد و وابستگی‌ها را نصب می‌کند
3. توکن‌ها و آیدی کانال‌ها را تعاملی از شما می‌پرسد و فایل `.env` را با دسترسی `600` می‌سازد
4. سرویس systemd را ثبت و **اجرای خودکار پس از ری‌استارت سرور** را فعال می‌کند
5. دستور `tbrctl` را نصب می‌کند
6. ربات را بالا می‌آورد و وضعیتش را نشان می‌دهد

---

## مدیریت ربات

```bash
tbrctl status
```

| دستور | کار |
|---|---|
| `tbrctl start` | روشن کردن ربات |
| `tbrctl stop` | خاموش کردن ربات |
| `tbrctl restart` | ری‌استارت ربات |
| `tbrctl status` | وضعیت سرویس + چند خط آخر لاگ |
| `tbrctl logs` | دیدن لاگ زنده (خروج با `Ctrl+C`) |
| `tbrctl logs -n 100` | ۱۰۰ خط آخر لاگ |
| `tbrctl config` | تغییر توکن‌ها و کانال‌ها، سپس ری‌استارت |
| `tbrctl update` | `git pull` + نصب مجدد وابستگی‌ها + ری‌استارت |
| `tbrctl enable` / `disable` | فعال/غیرفعال کردن اجرای خودکار پس از بوت |
| `tbrctl uninstall` | حذف سرویس (فایل‌ها و `.env` دست‌نخورده می‌مانند) |

اجرای خودکار پس از ری‌استارت سرور و همچنین ری‌استارت خودکار در صورت کرش، توسط systemd انجام می‌شود (`Restart=always`).

## تنظیمات

همهٔ کلیدها در فایل `.env` قرار دارند. برای دیدن فهرست کامل با توضیح هر کلید، [`.env.example`](.env.example) را ببینید.

کلیدهای ضروری:

```ini
bale_token=...
telegram_token=...
bale_channel_id=@your_bale_channel
telegram_channel_id=@your_telegram_channel
```

چند کلید پرکاربرد:

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `force_rtl` | `false` | افزودن نشانهٔ راست‌به‌چپ به ابتدای هر خط |
| `max_file_mb` | `45` | سقف حجم فایل؛ ربات‌های تلگرام بیش از ۵۰ مگابایت آپلود نمی‌کنند |
| `media_group_wait_seconds` | `1.2` | مدت انتظار برای جمع شدن کل آلبوم |
| `telegram_max_retries` | `5` | تعداد تلاش مجدد هنگام محدودیت ارسال یا قطعی شبکه |
| `sync_old_messages` | `false` | پردازش پست‌های صف‌مانده در اولین اجرا |

پس از تغییر دستی `.env`، یک `tbrctl restart` لازم است.

## عیب‌یابی

**ربات بالا نمی‌آید** — `tbrctl logs -n 50`. معمولاً یعنی توکن اشتباه است یا ربات ادمین کانال نیست.

**پست‌ها منتقل نمی‌شوند** — مطمئن شوید ربات بله ادمین کانال مبدأ است. برای دیدن اینکه چه چیزی دریافت و رد می‌شود، در `.env` مقدار `log_ignored_updates=true` را بگذارید و ری‌استارت کنید.

**فایل‌های بزرگ ارسال نمی‌شوند** — سقف آپلود ربات‌های تلگرام ۵۰ مگابایت است. فایل بزرگ‌تر رد می‌شود و یک پیام توضیحی به‌جای آن می‌آید (متن آن با `skipped_file_notice` قابل تغییر است).

**شروع دوباره از صفر** — سرویس را متوقف کنید و `.tbr_sync.db` را پاک کنید. این فایل هم نگاشت پیام‌ها و هم موقعیت صف بله را نگه می‌دارد.

## ساختار پروژه

```
main.py                 نقطهٔ ورود
setup_env.py            سازندهٔ تعاملی .env
install.sh              نصب یک‌دستوری + ثبت سرویس systemd
tbrctl                  ابزار start/stop/logs/config/update
tbr_sync/
  config.py             خواندن .env
  bale_api.py           کلاینت Bot API بله (دانلود استریمی با سقف حجم)
  telegram_api.py       ارسال به تلگرام (تلاش مجدد، دسته‌بندی آلبوم، برش امن متن)
  media.py              استخراج مدیا و تشخیص نوع فایل
  syncer.py             حلقهٔ اصلی، بافر آلبوم، ویرایش/حذف
  store.py              دیتابیس SQLite نگاشت پیام‌ها و offset
  text.py               تبدیل مارک‌داون بله به HTML تلگرام
tests/                  تست‌های pytest
```
